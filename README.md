# Music Shop

## Introduction
The project is a backend application for an online music shop.

## Technologies
- Spring
- Hibernate
- Postgresql
- Lombok

## Features
- Division into ADMIN and USER
- USER can:
    - sign up
    - log in
    - see all available products
    - add items to cart
    - delete items from cart
    - see all products in cart
    - check price of the cart
    - place an order
    - pay for the order
- ADMIN can:
    - log in
    - add/delete user
    - give role to user
    - see all users
    - divest role from user
    - add/delete product
    - see all products
    - see all carts
    - see all orders
    - change order's status
